FOUNDATION ROWS: THE BITS EVERY WORD SHARES IN THE INPUT WORD TABLES. PREDICTIONS, written 2026-10-07 before any
count was run. Results go below, after the runs; nothing above the RESULTS line is edited after a run.

HIS WORDS (2026-10-07), the only sentence quoted as his:
  "If we convert embedding table into base 2 can we find the base foundation that is in every token? Should be the
  same on ALL of them, some exact data from every single one"

THE SESSION'S RESTATEMENT (the session's words, not his): write every word's row of the input table in base 2. If
there is a foundation shared by all words, then at some (lane, place) every single word has the same bit. Those bits
are exact data present in every row; they can be written once, and each word stored as foundation + its own exact
remainder.

THE GRID (the session's reasoning): bits only line up across words if all words in a lane sit on one power of two.
So each lane is written on the finest place any of its words needs (its lowest lit place), every value an exact
whole number there. The places a lane spans are then set by its largest value (the top) and that grid (the bottom).

PREDICTION HANDED TO THIS RUN (the session's, copied as given):
  beyond the fresh draw, bits shared by every single word appear only at the sign and top places of a few big lanes
  (GPT-2: the same few lanes as T's column; Pythia: many lanes, since its tables lean hard; Qwen: few), broken in the
  rest by a handful of rare or never-built rows; with the 99.9% version (exceptions stored), the shared bits are a
  real foundation, but storing it once saves little beyond per-lane coding (under 0.3 bits a value), because a
  per-lane coder already pays almost nothing for a bit that never changes.
